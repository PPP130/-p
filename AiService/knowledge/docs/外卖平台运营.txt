外卖平台运营指南

平台评分体系：
1. 综合评分 = 商品评分 + 配送评分 + 服务评分
2. 商品评分：菜品口味、分量、包装
3. 配送评分：送达速度、配送态度
4. 服务评分：客服响应、售后处理
5. 评分低于4.5会影响店铺排名和流量

提升店铺排名的方法：
1. 保持高评分（4.8以上为优秀）
2. 提高出餐速度，控制在15分钟内
3. 参加平台活动获得流量加权
4. 保持稳定的营业时间和接单率
5. 优化菜品图片和描述，提高转化率

平台抽成规则：
1. 美团：技术服务费+履约服务费，综合约15-25%
2. 饿了么：佣金比例约15-23%
3. 自配送可降低部分费用
4. 新店有流量扶持期，通常7-14天
5. 参加平台活动可能有额外抽成

菜单设计技巧：
1. 菜品数量控制在30-50个，不宜过多
2. 分类清晰：招牌菜、热销菜、套餐、饮品、主食
3. 设置引流款（低价高销量）和利润款（高毛利）
4. 套餐组合比单点便宜5-10元，提高客单价
5. 菜品图片统一风格，白底或浅色背景

差评应对策略：
1. 差评必须24小时内回复
2. 先道歉，再解释，最后给解决方案
3. 常见差评话术：
   - 分量少："感谢反馈，已记录并调整，下次为您加量"
   - 口味差："很抱歉没能让您满意，我们已优化配方"
   - 送餐慢："出餐延误深表歉意，已优化厨房流程"
4. 引导顾客修改差评：私信沟通+补偿优惠券
5. 定期分析差评原因，针对性改进

新店开业运营：
1. 开业前3天设置大力度优惠（满20减15）
2. 准备充足的库存和人手
3. 开业期间延长营业时间
4. 积极回复每一条评价
5. 利用平台新店流量扶持期快速积累销量和好评

高峰期应对：
1. 提前准备半成品，缩短出餐时间
2. 设置预计出餐时间，管理顾客预期
3. 高峰期限制接单数量，保证品质
4. 增加临时人手或外包部分工序
5. 高峰后及时补充库存

数据关注指标：
1. 曝光量：店铺被多少人看到
2. 进店转化率：看到后进入店铺的比例
3. 下单转化率：进入后实际下单的比例
4. 复购率：回头客占比
5. 客单价：平均每单金额
