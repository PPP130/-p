食品安全管理规范

食材采购要求：
1. 选择有资质的供应商，保留营业执照和食品经营许可证
2. 生鲜食材每日采购，确保新鲜度
3. 预包装食品检查生产日期和保质期
4. 索取并保存进货凭证和检验合格证明
5. 建立食材台账，记录来源和数量

食材存储规范：
1. 冷藏温度0-4℃，冷冻温度-18℃以下
2. 生熟分开存放，避免交叉污染
3. 食材离墙离地存放，保持通风
4. 先进先出原则，避免过期
5. 每日检查冰箱温度并记录

厨房卫生标准：
1. 厨房地面无积水、无油污
2. 操作台面每餐前后清洁消毒
3. 刀具砧板生熟分开，定期消毒
4. 抽油烟机每周清洗一次
5. 垃圾桶加盖，日产日清

从业人员要求：
1. 持有效健康证上岗，每年体检一次
2. 工作时穿戴整洁的工作服和帽子
3. 操作前洗手消毒，接触生食后必须洗手
4. 患有传染性疾病立即调离岗位
5. 不在厨房内吸烟、吃东西

食品加工规范：
1. 食材清洗至少三遍，去除杂质和农药残留
2. 肉类必须充分加热，中心温度达70℃以上
3. 凉菜制作在专间内操作，温度不超过25℃
4. 成品菜肴2小时内食用，超过需冷藏保存
5. 隔夜饭菜彻底加热后方可出售

常见食品安全风险：
1. 亚硝酸盐中毒：不使用工业盐，腌制品充分浸泡
2. 细菌性食物中毒：食材彻底加热，避免长时间常温放置
3. 农药残留：蔬菜浸泡清洗，必要时使用果蔬清洗剂
4. 交叉污染：生熟分开处理，工具不混用
5. 过敏原管理：菜单标注常见过敏原（花生、海鲜、麸质等）

外卖包装安全：
1. 使用食品级包装材料，有QS标志
2. 汤类使用防洒漏密封容器
3. 热菜和冷菜分袋包装
4. 包装袋标注店铺信息和出餐时间
5. 定期检查包装材料是否有异味或变质
