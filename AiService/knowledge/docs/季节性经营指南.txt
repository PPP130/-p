季节性经营指南

春季经营要点（3-5月）：
1. 推出春季时令菜品：春笋、荠菜、香椿等
2. 菜品偏清淡爽口，减少油腻菜品
3. 增加沙拉、凉菜等品类
4. 清明、五一节日营销活动
5. 换季注意食材保鲜，温度回升易变质

夏季经营要点（6-8月）：
1. 增加冷饮、冰品、凉面等消暑品类
2. 食品安全重点：高温易变质，缩短食材存放时间
3. 包装加强密封，防止高温下洒漏变质
4. 午间订单高峰期提前备料
5. 夏季夜宵市场大，可延长营业时间
6. 推出轻食、低卡套餐迎合健康需求

秋季经营要点（9-11月）：
1. 推出秋季滋补菜品：炖汤、砂锅等
2. 中秋、国庆双节营销重点期
3. 秋季食材丰富，可推出限定菜品
4. 天气转凉，热汤类、火锅类需求上升
5. 双11大促活动准备

冬季经营要点（12-2月）：
1. 主打暖身菜品：火锅、麻辣烫、砂锅粥
2. 冬季食材成本上升，提前锁定供应商价格
3. 元旦、春节、元宵节密集营销期
4. 低温配送注意保温，使用保温袋
5. 春节期间可推出年夜饭套餐、半成品菜
6. 寒假期间学生客流减少，调整营销策略

天气因素应对：
1. 雨雪天：外卖订单激增，提前备货，增加配送人手
2. 高温天：加强冷链管理，缩短配送范围
3. 极端天气：及时更新营业状态，避免接单后无法配送
4. 空气质量差：推出润肺养生类菜品

节假日营销日历：
- 1月：元旦、年货节
- 2月：情人节、春节、元宵节
- 3月：妇女节、植树节
- 4月：清明节
- 5月：劳动节、母亲节
- 6月：儿童节、端午节、父亲节、618
- 7-8月：暑假、七夕
- 9月：开学季、中秋节、教师节
- 10月：国庆节、重阳节
- 11月：双11、感恩节
- 12月：双12、圣诞节、跨年

淡旺季经营策略：
1. 旺季（春节、国庆等）：加大备货、增加人手、主推套餐
2. 淡季（暑假、开学季等）：推出优惠活动、开发新品、维护老客户
3. 每月定期推出1-2款新品保持新鲜感
4. 利用淡季培训员工、优化流程、更新设备
